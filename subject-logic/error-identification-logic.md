# 错题判定逻辑规则

> **版本**: 2.0 (2026-05-14)
> **核心变更**: 引入「单卷单模式」约束——每张试卷只使用一种批改方式，消除多模式混杂导致的误判。
> **原则**: 宁可漏判不要误判；不确定时默认为"做对"。

---

## 〇、模式选择（前置决策）

**一张试卷只使用一种批改方式。** VL/预处理首先判断试卷属于哪种模式，后续全部使用该模式的判定规则。

### 模式 A：勾叉核对（✓✗ Mode）

**特征**: 教师/同学在每道题旁标注 ✓ 或 ✗。
- ✓ = 对
- ✗ = 错
- 可能伴随扣分标记（-2, -0.5）
- **不关心**其他红笔标记（圈画、下划线等——视为噪音，忽略）

**适用试卷**: yingyu34 类型——选项旁有红笔勾叉

### 模式 B：标注正确答案（Correct Answer Mode）

**特征**: 教师/同学在每道题的选项旁或题目旁用红笔写出正确答案（字母/数字/单词）。
- 红笔写了正确答案 = 学生做错了（教师纠正）
- **不关心**是否有勾叉符号
- 核心逻辑: `红笔标注答案 ≠ 学生原答案 → 错题`

**适用试卷**: yingyu33 类型——红笔标注正确答案字母

### 模式判定流程

```
试卷 →
│
├─ 预处理扫描全卷红笔区域 →
│  ├─ 红笔符号以 ✓/✗ 为主 → 模式 A（勾叉核对）
│  ├─ 红笔符号以字母/数字为主 → 模式 B（标注正确答案）
│  ├─ 两种都存在 → 按多数判定，标记不确定的题目
│  └─ 无红笔 → 跳过（未批改试卷）
```

**⚠️ 关键约束**：一旦确定模式，**仅使用该模式的规则判定**。另一模式的标记视为噪音并忽略。
例如：模式 A 下，红笔写的字母不被读作"正确答案"；模式 B 下，随手画的斜线不读作 ✗。

## 一、模式 A：勾叉核对判定规则

### A.1 判定决策树

```
一道题 →
│
├─ 有红笔 ✗ 吗？
│  ├─ 是 → ❌ 错题
│  └─ 否 ↓
│
├─ 有红笔 ✓ 吗？
│  ├─ 是 → ✅ 对
│  └─ 否 ↓
│
├─ 有红笔划掉/覆盖原答案吗？
│  ├─ 是 → ❌ 错题（划掉 = 否定）
│  └─ 否 ↓
│
├─ 有红笔扣分标记（-2, -0.5 等）吗？
│  ├─ 是 → ❌ 错题
│  └─ 否 ↓
│
└─ 无上述红笔标记 → ✅ 对（标记为"无批改标记"，需人工复核确认未漏批）
```

### A.2 忽略项（模式 A 下不参与判定）

| 红笔内容 | 处理 |
|---------|------|
| 圈出题号/选项 | 忽略（可能是教师标记重点） |
| 下划线/波浪线 | 忽略 |
| 红笔写的字母/数字 | 忽略（不是 ✓✗ 标记） |
| 红笔中文注释 | 忽略 |
| 红笔边框/分隔线 | 忽略 |

### A.3 输出规范

```json
{
  "mode": "check_cross",
  "questionNumber": <题号>,
  "isError": <boolean>,
  "confidence": "high|medium|low",
  "evidence": {
    "hasCross": <boolean>,
    "hasCheck": <boolean>,
    "hasStrikethrough": <boolean>,
    "hasScore": <boolean>,
    "redMarkDescription": "<一句话>"
  }
}
```

## 二、模式 B：标注正确答案判定规则

### B.1 判定决策树

```
一道题 →
│
├─ 有红笔标注正确答案（字母/数字/单词）吗？
│  ├─ 否 → ✅ 对（标记为"无批改标记"）
│  └─ 是 ↓
│     ├─ 红笔答案 ≠ 学生原答案 → ❌ 错题
│     ├─ 红笔答案 = 学生原答案 + 有否定标记 → ❌ 错题
│     └─ 红笔答案 = 学生原答案 + 无否定标记 → ✅ 对
│
├─ 有红笔 ✗ 吗？（模式 B 中 ✗ 为辅）
│  ├─ 是 → ❌ 错题
│  └─ 否 → (不影响判定)
```

### B.2 忽略项（模式 B 下不参与判定）

| 红笔内容 | 处理 |
|---------|------|
| 圈出题号/选项 | 忽略 |
| 下划线/波浪线 | 忽略 |
| ✓ 符号 | 忽略（此模式下非主要判定依据） |
| 中文注释 | 忽略 |

### B.3 输出规范

```json
{
  "mode": "correct_answer",
  "questionNumber": <题号>,
  "isError": <boolean>,
  "studentAnswer": "<学生答案>",
  "correctAnswerFromRed": "<红笔标注答案>",
  "confidence": "high|medium|low",
  "evidence": {
    "hasCorrectAnswerWritten": <boolean>,
    "studentVsRedMismatch": <boolean>,
    "hasCross": <boolean>,
    "redMarkDescription": "<一句话>"
  }
}
```

## 三、置信度输出

| 条件 | 置信度 |
|------|--------|
| 模式 A: 清晰 ✗ + 无歧义 | high |
| 模式 A: 清晰 ✓ + 无其他标记 | high |
| 模式 B: 红笔答案清晰 + 学生答案清晰 + mismatch | high |
| 模式 B: 红笔答案清晰 + 学生答案清晰 + match | high |
| 标记潦草/不清晰 | medium |
| 无任何批改标记 | low（可能是漏批） |
| 标记与文字重叠难以分辨 | low |
| 模式判定不确定 | low |

## 四、特殊场景

### 4.1 学生互批
- 不改变模式判定逻辑
- confidence 降一级（high→medium, medium→low）

### 4.2 跨页续题
- 题号延续前一页 → 同样按当前模式判定
- 只包含选项无题干的残题 → 也按模式判定（只要能定位选项区域）

### 4.3 印刷红色干扰
- 预处理层（HSV 颜色分离/位置过滤）负责滤除
- 若仍有残留被 VL 看到 → prompt 明确"印刷红色不是批改"

## 五、与 v1.0 的差异

| | v1.0 | v2.0 |
|---|---|---|
| 批改模式 | 混合（同时处理所有类型） | 单卷单模式 |
| 判定规则 | 8 种标记类型全参与 | 仅模式对应标记参与 |
| 噪音处理 | 无明确忽略逻辑 | 非本模式标记全部忽略 |
| 模式切换 | 无 | VL 预处理阶段判定 |
| 预期精度 | 25% 精确率 | 目标 80%+（去噪后） |
