# 错题判定逻辑规则

> **版本**: 2.1 (2026-05-14)
> **核心变更**: 废弃「模式二选一」——同一张试卷上 ✗ 和红笔字母可共存，统一判定。
> **核心原则**: 手写红笔在答案区 = 批改。印刷红色、非手写红笔标记 = 噪音忽略。
> **总原则**: 宁可漏判不要误判；不确定时默认为"做对"。

---

## 〇、唯一判定标准

**错题 = 学生手写答案旁边出现了手写红笔叉（✗）或手写红笔英文/数字。**

| 红笔内容 | 是否批改 | 判定 |
|---------|---------|------|
| 手写红色 ✗（叉号） | ✅ 是 | ❌ 错题 |
| 手写红色英文字母/单词，标注在手写答案旁 | ✅ 是 | ❌ 错题（教师纠正） |
| 手写红色数字，标注在答案旁 | ✅ 是 | ❌ 错题（扣分/纠正） |
| 手写红色 ✓（勾号） | ✅ 是 | ✅ 对题 |
| 红笔圈画（圈题号、圈选项） | ❌ 否 | 忽略 |
| 红笔下划线/波浪线 | ❌ 否 | 忽略 |
| 红笔边框/分隔线 | ❌ 否 | 忽略 |
| 印刷红色文字/图案 | ❌ 否 | 忽略 |
| 红笔中文注释 | ❌ 否 | 忽略 |
| 无任何手写红笔标记 | — | ✅ 对（标记"无批改"，需复核） |

## 一、判定决策树

```
一道题 →
│
├─ 学生答案区附近有手写红笔 ✗ 吗？
│  ├─ 是 → ❌ 错题 (confidence: high)
│  └─ 否 ↓
│
├─ 学生答案区附近有手写红笔 ✓ 吗？
│  ├─ 是 → ✅ 对 (confidence: high)
│  └─ 否 ↓
│
├─ 学生手写答案旁边有手写红笔字母/单词/数字吗？
│  ├─ 是 → ❌ 错题 (教师标注了正确答案，confidence: high)
│  └─ 否 ↓
│
├─ 有红笔划掉/覆盖学生原答案吗？
│  ├─ 是 → ❌ 错题 (confidence: high)
│  └─ 否 ↓
│
└─ 无上述手写红笔标记 → ✅ 对 (confidence: low，标记为"无批改标记"，需人工复核)
```

## 二、"手写红笔" vs "印刷红色" 区分

**这是判定的前提。** 区分方式：

| 维度 | 手写红笔 | 印刷红色 |
|------|---------|---------|
| 位置 | 紧贴学生答案区域 | 试卷固定位置（标题/边框/装饰） |
| 笔迹 | 不规则、粗细变化、有笔锋 | 均匀、规整、字体一致 |
| 颜色 | 单一红色（可能有深浅） | 与试卷其他印刷红色色值一致 |
| 上下文 | 只在有学生作答的题目旁出现 | 全卷均匀分布 |

**VL prompt 指令**: "红色印刷文本（如试卷标题、边框装饰、页码）不是批改标记，请忽略。只关注学生手写答案区附近的非印刷红色笔迹。"

## 三、英语科目特殊规则

### 3.1 选择题（A/B/C/D）

- 学生答案 = 选项字母（可能印在选项旁，或写在题号旁）
- 手写红笔 ✗ 在选项旁 → ❌ 错题
- 手写红笔 ✓ 在选项旁 → ✅ 对题
- 手写红笔字母（如 "C"）写在学生选的选项旁 → ❌ 错题（教师标注正确答案）
- **关键**: 必须区分"印刷的 A/B/C/D"和"手写红笔字母"

### 3.2 填空题/语法填空

- 学生将答案手写在空格中
- 手写红笔 ✗ 在填写处 → ❌ 错题
- 手写红笔单词写在学生答案上方/旁 → ❌ 错题（教师纠正）
- 手写红笔 ✓ 在填写处 → ✅ 对题

### 3.3 翻译/写作

- 整段手写文本
- 红笔划线/圈/批注 → 不逐句判断，整题标记为"有批改需查看"
- 红笔打分 → 看分数判定

## 五、置信度规则

| 条件 | 置信度 |
|------|--------|
| 清晰手写红笔 ✗ | high |
| 清晰手写红笔 ✓ | high |
| 清晰手写红笔字母/单词在答案旁 | high |
| 手写红笔字母潦草/不清晰 | medium |
| 无任何手写红笔标记 | low（可能漏批） |
| 手写与印刷红色难以区分 | low |
| 学生互批场景 | 降一级（high→medium, medium→low） |

## 六、与旧版本差异

| | v1.0 (原始) | v2.0 (废弃) | v2.1 (当前) |
|---|---|---|---|
| 思路 | 混合判断所有红笔 | 单卷单模式（A/B择一） | 手写红笔=批改 |
| 问题 | 8类标记全参与，精度25% | ✗和字母不能共存，不符合实际 | — |
| 判定 | 看见红笔就猜错 | 模式内规则 | ✗ 或手写字母 = 错 |
| 噪音过滤 | 无 | 非本模式标记忽略 | 非手写红笔全部忽略 |
