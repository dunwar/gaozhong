# 错题判定逻辑规则

> **版本**: 3.0 (2026-05-24)
> **核心原则**: 手写红笔在答案区 = 批改。但只有两种批改标记代表「做错」，其余均代表「做对或中性」。
> **总原则**: 宁可漏判不要误判；不确定时默认为"做对"。

---

## 〇、唯一判定标准

**错题 = 学生手写答案旁边出现了以下两种标记之一：**

| 红笔标记 | 判定 | 说明 |
|---------|------|------|
| 手写红色 ✗（叉号） | ❌ 错题 | 教师明确标记做错 |
| 手写红笔字母/单词/数字，写在学生答案旁边 | ❌ 错题 | 教师标注了正确答案，说明学生答案错误 |

**以下红笔标记均不代表做错：**

| 红笔标记 | 判定 | 说明 |
|---------|------|------|
| 手写红色 ✓（勾号） | ✅ 对题 | 教师确认正确 |
| 红笔圈出选项/题号 | ✅ 忽略 | 标记重点，非判错 |
| 红笔下划线/波浪线 | ✅ 忽略 | 标记重点，非判错 |
| 红笔汉字注释 | ✅ 忽略 | 教学笔记，非判错 |
| 红笔边框/分隔线 | ✅ 忽略 | 版面标记 |
| 印刷红色文字/图案 | ✅ 忽略 | 非批改，是试卷印刷 |
| 无任何手写红笔标记 | ✅ 对 | 未批改 = 默认正确 |

---

## 一、判定决策树（极简版）

```
一道题 →
│
├─ 学生答案区附近有手写红笔 ✗ 吗？
│  ├─ 是 → ❌ 错题
│  └─ 否 ↓
│
├─ 学生手写答案旁边有手写红笔字母/单词/数字吗？
│  ├─ 是 → ❌ 错题（教师标注了正确答案，学生答案不同即错）
│  └─ 否 → ✅ 对（或中性，无需处理）
```

**不需要判断的标记**（直接跳过）：✓、圈画、下划线、波浪线、汉字注释、边框、印刷红色。

---

## 二、各红笔标记意图表

| 看见什么 | 教师意图 | 判定 |
|---------|---------|------|
| 红笔 ✗ 在答案旁 | "这题做错了" | ❌ 错 |
| 红笔划掉学生原答案 + 旁边写新字母 | "你选A错了，正确答案是B" | ❌ 错，correctAnswer=红笔写的 |
| 红笔只写新字母，没划掉原答案 | "正确答案是B"（学生原选≠B即错）| ❌ 错，原选≠红笔字母 |
| 红笔只写新字母 = 学生原选 | 可能是学生自己写的或教师确认 | ✅ 对 |
| 红笔 ✓ 在答案旁 | "做对了" | ✅ 对 |
| 红笔圈出某个选项 | 标记重点 | ✅ 忽略 |
| 红笔下划线在题干下方 | 标记重点句子 | ✅ 忽略 |
| 红笔写"主谓一致""过去式"等汉字 | 教学笔记 | ✅ 忽略 |
| 红笔 "-2" "-0.5" 扣分 | 扣分=错了 | ❌ 错 |
| 此题无任何红笔标记 | 未批改 | ✅ 对（标记需复核） |

## 三、"手写红笔" vs "印刷红色" 区分

| 维度 | 手写红笔 | 印刷红色 |
|------|---------|---------|
| 位置 | 紧贴学生答案区域 | 试卷固定位置（标题/边框/装饰） |
| 笔迹 | 不规则、粗细变化、有笔锋 | 均匀、规整、字体一致 |
| 颜色 | 单一红色（可能有深浅） | 与试卷其他印刷红色色值一致 |
| 上下文 | 只在有学生作答的题目旁出现 | 全卷均匀分布 |

## 四、英语科目场景适配

### 4.1 选择题
- 学生答案印/写在题号旁或选项旁
- ✗ 在答案旁 → ❌ 错
- 红笔字母写在答案旁（如 "B"）→ 对比学生原选：不同则 ❌，相同则 ✅
- ✓ 在答案旁 → ✅ 对（忽略）

### 4.2 填空题/语法填空
- 学生手写答案在空格中
- ✗ 在填写处 → ❌ 错
- 红笔单词写在学生答案上方/旁 → ❌ 错（教师纠正）
- ✓ 在填写处 → ✅ 对（忽略）

### 4.3 完形填空
- 题号旁红笔字母（大写 A/B/C/D）→ 正确答案标注，对比学生原选
- 题号旁红笔 ✓ → ✅ 对（忽略）
- 题号旁红笔 ✗ → ❌ 错

### 4.4 翻译/写作
- 红笔划线/圈/批注 → 不逐句判断，整题标记
- 红笔打扣分（-1/-2）→ ❌ 错

## 五、置信度

| 条件 | 置信度 |
|------|--------|
| 清晰手写红笔 ✗ | high |
| 清晰手写红笔字母 ≠ 学生答案 | high |
| 清晰手写红笔 ✓ | 直接跳过，不算错题 |
| 手写红笔字母 ≠ 学生答案，但笔迹潦草 | medium |
| 无任何手写红笔标记 | low（可能漏批，标记需复核） |
