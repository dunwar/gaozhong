# 错题判定逻辑规则

> **版本**: 1.0 (2026-05-11)
> **用途**: 定义教师/同学批改后的试卷上「如何判断一道题是错题」的规则引擎。
> **使用方**: VL 判错 prompt 引用本文逻辑；代码层可作为校验 fallback。
> **原则**: 宁可漏判不要误判；不确定时默认为"做对"。

---

## 一、核心认识

**我们不做批改。** 学校老师/学生自己已经做了批改。我们只做「阅读批改结果 → 判定对错」。
试卷上的批改标记是**输入**，不是我们生成的。我们需要正确理解这些标记的语义。

---

## 二、批改标记识别层级

### 第1层：标记类型识别（看图说话）

VL 模型看图，输出每道题的红笔标记类型：

| 标记 | 视觉特征 | 变体 |
|------|---------|------|
| `cross` | 两条交叉斜线 ✗ | 草率小叉、大叉覆盖全题 |
| `check` | 弧线加竖勾 ✓ | 草率勾、半勾 |
| `correct_answer` | 红笔手写字母/数字/单词 | 可能写选项旁、题号旁、或覆盖原答案上方 |
| `underline` | 下划线/波浪线 | 可能是教师标记重点非判错 |
| `circle` | 红圈围住某内容 | 围住题号、选项字母、或完整答案区 |
| `strikethrough` | 横线划掉/斜线覆盖 | 覆盖学生原答案 |
| `annotation` | 红笔汉字/短句注释 | 如"注意""过去式""时态" |
| `score` | 红笔数字（如"-2"、分数） | 扣分标记 |

### 第2层：标记意图推断（理解语义）

在同一道题上可能存在多个标记的组合，需要推断教师意图：

| 组合模式 | 教师意图 | 判定 |
|---------|---------|------|
| 仅 ✓ | 做对了 | ✅ 对 |
| 仅 ✗ | 做错了 | ❌ 错 |
| ✗ + 红笔正确答案 | 做错了，给出正确解 | ❌ 错 |
| 红笔正确答案（无✗无划掉） | 标注正确答案 = 暗示学生做错了 | ❌ 错（需对比学生答案确认） |
| 红笔正确答案 = 学生答案 | 学生在教师公布答案后自行补写的 | ？需按科目规则判断 |
| 红笔圈出学生答案 | 可能表示"看看这里" | ？需看有没有其他标记组合 |
| 仅下划线/波浪线 | 标记重点，非判错 | ✅ 对 |
| 仅汉字注释 | 教学提示，非判错 | ✅ 对 |
| ✗ 划掉部分内容，旁写修改 | 部分错误，修正 | ❌ 错 |

### 第3层：学生答案对比（交叉验证）

当红笔给出正确答案时，需要对比：

```
if (红笔正确答案存在) {
  if (学生答案 ≠ 红笔正确答案) → 错题 ❌
  if (学生答案 = 红笔正确答案) → 需看红笔是否还有其他否定标记
  if (学生未作答) → 待确认，标记为需人工审核
}
```

## 三、判定决策树

```
一道题 →
│
├─ 有红笔 ✗ 吗？
│  ├─ 是 → ❌ 错题
│  └─ 否 ↓
│
├─ 有红笔划掉/覆盖原答案吗？
│  ├─ 是 → ❌ 错题
│  └─ 否 ↓
│
├─ 有红笔写正确答案/正确选项字母（非学生笔迹）吗？
│  ├─ 是 →
│  │  ├─ 红笔答案 ≠ 学生原答案 → ❌ 错题
│  │  ├─ 红笔答案 = 学生原答案 AND 有其他否定标记 → ❌ 错题
│  │  └─ 红笔答案 = 学生原答案 AND 无否定标记 → ✅ 对（教师确认正确）
│  └─ 否 ↓
│
├─ 有红笔扣分标记（如 -2, -5）吗？
│  ├─ 是 → ❌ 错题（扣分 = 错）
│  └─ 否 ↓
│
├─ 有红笔 ✓ 吗？
│  ├─ 是 → ✅ 对
│  └─ 否 ↓
│
├─ 有红笔圈/下划线/注释（非判错标记）吗？
│  ├─ 是 → ✅ 对（标记重点，非判错）
│  └─ 否 ↓
│
└─ 无任何红笔标记 → ✅ 对
```

## 四、特殊场景处理

### 4.1 学生互批场景

学生用红笔代替老师批改同学作业：
- 红笔批改**可能不准**（学生水平有限）
- 红笔 ✗ 或写正确答案 → 仍需当作教师批改处理（系统无法区分批改者身份）
- 但 confidence 降为 "medium"

### 4.2 多色笔场景

非红笔（蓝/绿/紫笔）批改：
- 默认不处理（需要预处理层先识别是否存在非红批改）
- 如果预处理层标记了非红批改 → 同逻辑处理，但标记 `penColor: "blue"/"green"/"purple"`

### 4.3 作文/主观题

- 作文有红笔划线/圈/批注 → 不逐句判断，整题标记为"需查看"
- 翻译/填空有红笔改写 → 按存在红笔正确答案处理

### 4.4 印刷红色干扰

教材/试卷本身的红色印刷（标题、边框、装饰）：
- 预处理层（红笔分离 opencv）应已过滤
- 如果仍有残留 → VL prompt 中明确"红色印刷不是批改，忽略"

## 五、输出规范

每道题判定后输出：

```json
{
  "questionNumber": <题号>,
  "isError": <boolean>,
  "studentAnswer": "<学生答案>",
  "correctAnswer": "<正确答案或空>",
  "confidence": "high|medium|low",
  "evidence": {
    "redMarkTypes": ["<标记类型>"],
    "hasCross": <boolean>,
    "hasCorrectAnswerWritten": <boolean>,
    "studentVsRedMismatch": <boolean>,
    "teacherIntent": "<一句话描述教师批改意图>"
  }
}
```
