# 英语科目题型与批改逻辑

> **版本**: 1.1 (2026-05-11)
> **定位**: 模块化科目逻辑文件，定义英语试卷的题型、答题方式、批改约定。
> **配合**: `error-identification-logic.md` 负责「判定规则」，本文件负责「题型结构」。
> **范围**: 包含上海高考题型 + 日常练习题型（默写、句型转换等）。

## 二、题型详解及答题方式

### 2.1 语法填空 (Grammar, Section A)

- **形式**: 一段短文挖空（10个空），在空格处填写单词正确形式
- **答题方式**: 直接在空格处填写（手写英文单词），无选项
- **批改约定**:
  - 教师直接在填写处用红笔 ✓ 或 ✗
  - 错误时红笔写出正确答案
  - 批改符号通常覆盖在学生答案上方/旁
- **错题本适用性**: ✅ 高 — 可提取错误答案和正确答案

### 2.2 选词填空 (Vocabulary, Section B)

- **形式**: 给出 10+ 候选词，选词填入短文 10 个空
- **答题方式**: 填写单词原形或变形（手写），可能同时标序号/字母
- **批改约定**:
  - 教师在空格处 ✓ 或 ✗
  - 错误时写正确答案
- **错题本适用性**: ✅ 高 — 词汇考点明确

### 2.3 完形填空 (Cloze)

- **形式**: 短文 15 个空，每题 A/B/C/D 四选一
- **答题方式**: 在选项中圈出/涂黑/写字母，或在题号前写字母
  - 常见做法：直接在选项前打✓选择，或圈出选项字母
- **批改约定**:
  - 教师在最左侧/题号旁打 ✓ 或 ✗
  - 错误时可能在题号旁写正确答案字母（红色大写字母）
  - 这是最常见的上海高中英语批改模式：一列红笔字母对应题号
- **错题本适用性**: ✅ 高 — 这是核心题型
- **⚠️ 特殊注意**:
  - 题号旁红笔写的字母 = 正确答案（非学生答案）
  - 需区分「学生作答笔迹」和「教师批改笔迹」
  - 学生可能用蓝黑笔在题号旁写了答案。如果红笔字母与之不同 → 错题

### 2.4 阅读理解 (Reading)

- **形式**: 3 篇阅读文章 + 选择题 (A/B/C/D)
- **答题方式**:
  - 同完形填空：在选项上标记或题号旁写答案字母
- **批改约定**:
  - 同完形填空
  - 阅读理解文章部分不会有批改标记
- **错题本适用性**: ✅ 高 — 但题干区域较大（含文章段落），裁切需包含文章关键信息

### 2.5 六选四 (Gapped Text)

- **形式**: 从 6 个选项中选 4 个填入文章空白处
- **答题方式**: 填写选项编号或字母
- **批改约定**: 同上，红笔在题号旁 ✓ ✗ 或写正确选项
- **错题本适用性**: ✅ 中 — 需要文章上下文才能理解

### 2.6 翻译 (Translation)

- **形式**: 给出中文句子，译成英文
- **答题方式**: 在横线上书写完整英文句子
- **批改约定**:
  - 教师用红笔修改错处（划掉+改写）
  - 或在行末打 ✓ ✗
  - 可能标注扣分（如 -1, -0.5）
- **错题本适用性**: ⚠️ 低 — 翻译错误不定点，不适合逐题整理。可记录但不做深入分析

### 2.7 写作 (Writing)

- **形式**: 命题作文，约 120-150 词
- **答题方式**: 在横线/空白处书写完整文章
- **批改约定**:
  - 教师红笔划线、圈出、批注
  - 打分/扣分
- **错题本适用性**: ❌ 不适用 — 作文是多维度评估，不是单题对错


## 二、日常练习题型（非高考，学校常见）

### 2.8 默写/听写 (Dictation)

- **形式**: 序号列表（如 1. _____ 2. _____），学生根据中文释义/读音写出英文单词/短语
- **答题方式**: 手写单词/短语，无选项
- **⚠️ VL 检测要点**:
  - 布局紧凑多行排列，每行 = 序号 + 手写答案
  - 无 A/B/C/D 选项、无成段题干
  - 行间距小（可能仅 30-50px），可能多栏
  - 题号连续排列（如 1-30）
- **批改约定**: 教师直接改正（划掉+上写正确答案）或打 ✓
- **错题本适用性**: ✅ 高 — 每题独立，错误明确

### 2.9 句型转换 (Sentence Transformation)

- **形式**: 给出原句 + 提示词，改写句子。如 "He is too young to drive. → not ___ to drive"
- **批改约定**: 红笔改正或打 ✓
- **错题本适用性**: ✅ 高

### 2.10 选词填空/综合填空（日常版）

- **形式**: 短文挖空 + 备选词框
- **批改约定**: 红笔 ✓✗ 或改正
- **错题本适用性**: ✅ 高


## 三、英语批改标记的典型分布模式

### 模式 A: 题号旁批改（最常见）

```
21. A B C Ⓓ     ← 红笔在 D 上打 ✓（学生选了 D，对了）
22. Ⓐ B C D     ← 红笔在 A 上圈✓，旁边写"B"（学生选 A 错了，正确答案 B）
```

**判定规则**:
- ✓ 在某个选项上 → 该题为对
- ✗ + 红笔写另一个选项字母 → 错题，正确选项为红笔写的

### 模式 B: 题号列批改

```
21. ✓           ← 对了
22. ✗ C        ← 错了，红笔写 C 为正确答案  
23. ✓
24. ✗ A        ← 错了，正确答案 A
```

**判定规则**:
- 红笔 ✓ → 对
- 红笔 ✗ + 字母 → 错，字母=正确答案

### 模式 C: 混合批改（yingyu33 类型）

```
21. ✓           ← 对了
22. （题号旁什么红笔标记都没有，但正确答案已写）→ ...
```

等等，用户说 yingyu33 红笔提供正确答案 + 标注，6道错题。

实际上我应该更仔细地看 yingyu33 的图。但我之前看了 — yingyu33 是两个 page 的 multiple choice。用户说红笔标注正确答案，应有6道错。

这其实是：教师在每题题号旁写正确答案字母，学生答案不符 → 错。

**判定规则（yingyu33 场景）**:
- 红笔写了正确答案字母（无✗）→ 如果学生原选 ≠ 红笔字母 → 错题
- 红笔写了正确答案字母（无✗）→ 如果学生原选 = 红笔字母 → 对

### 模式 D: 纯勾叉批改（yingyu34 类型）

```
21. ✓           ← 对
22. ✗           ← 错（没写正确答案）
23. ✓
```

**判定规则**:
- ✗ → 错
- ✓ → 对

## 四、英语科目特殊规则

### 4.1 笔迹颜色区分

| 颜色 | 角色 | 说明 |
|------|------|------|
| 蓝/黑色 | 学生作答 | 原始答案 |
| 红色 | 教师批改 | 批改标记（✓✗）和正确答案 |
| 其他色（绿/紫） | 可能是学生互批 | 按相同逻辑处理 |

### 4.2 字母含义

选择题中字母 A/B/C/D/E/F 可能出现在两个位置：
- **题号旁**: 学生写的答案 → 蓝/黑色
- **题号旁另一侧**: 教师写的正确答案 → 红色

关键识别：**同一题周围出现两个字母且颜色不同 → 红色的是正确答案**

### 4.3 阅读理解特殊处理

阅读理解需要裁切包含文章段落的区域，但要标注哪些行是原文，哪些是题目。否则 VL 判错时可能混淆文章内容和题目。
